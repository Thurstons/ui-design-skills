# UI Terminology

Use this reference to interpret colloquial feedback. Select terms by context; the rows are hypotheses, not fixed replacements.

| User expression | Candidate professional terms | Check before using |
|---|---|---|
| 页面太挤 | high information density; insufficient whitespace; compressed vertical rhythm | Is the problem density, poor grouping, or both? |
| 看起来很廉价 | weak visual hierarchy; inconsistent styling; excessive decoration; low finish quality | Identify observable causes instead of repeating the judgment. |
| 高级一点 | restrained; refined; premium; coherent; high finish quality | Check which traits matter and whether they conflict with the brand. |
| 卡片太多 / 一坨一坨 | over-containerization; excessive sectional fragmentation | Could whitespace, dividers, or typography group the content? |
| 按钮太抢眼 | excessive CTA visual weight; weak action hierarchy | Which action is primary? |
| 字有点乱 | weak typography hierarchy; inconsistent type scale; poor rhythm | Check size, weight, line-height, alignment, and number of styles. |
| 不够科技感 | insufficient technical visual cues; conventional visual language | Do not equate “tech” with neon, gradients, or glow by default. |
| 页面太平 | insufficient depth; weak contrast hierarchy; unclear grouping | Depth may come from spacing and tone, not only shadows. |
| 页面太花 | excessive visual noise; competing accents; high chroma; decorative overload | Identify the dominant sources of noise. |
| 别全都是框 | reduce bordered containers; use whitespace grouping; flatter hierarchy | Preserve boundaries needed for comprehension. |
| 信息分层明显 | strong information hierarchy; progressive disclosure; salient primary content | State which content tier should dominate. |
| 动起来高级一点 | restrained motion; purposeful micro-interactions; coherent easing | Motion must explain state or continuity. |
| 右边太空 | visual imbalance; asymmetric negative space; unsuitable grid ratio | Do not blindly add content. |
| 找不到重点 | weak focal point; competing hierarchy; insufficient task emphasis | Identify the primary task and decision. |
| 操作太绕 | excessive interaction cost; poor discoverability; unnecessary steps | Distinguish navigation from workflow complexity. |

## Evidence Language

- `observed`: directly visible in supplied screenshot, DOM, or code.
- `reported`: explicitly stated by the user.
- `inferred`: plausible interpretation supported by context.
- `unknown`: information needed for a confident decision is absent.
