# Style Dictionary

Translate style names into traits that another designer or agent can act on. Combine only compatible traits and explain any tension.

| Direction | Typical traits | Avoid reducing it to |
|---|---|---|
| Premium minimal | restrained palette, precise alignment, generous whitespace, low decoration, high finish | large whitespace alone |
| Content-first | content hierarchy leads; containers recede; decoration supports comprehension | removing all visual structure |
| Editorial | expressive type hierarchy, deliberate rhythm, strong imagery, asymmetric compositions when appropriate | oversized headings everywhere |
| Enterprise | predictable navigation, dense but ordered data, stable components, clear states | gray, visually flat interfaces |
| Technical | structured data, monospaced accents where meaningful, precise states, system feedback | neon gradients and glowing borders |
| Friendly | warm tone, approachable language, softened geometry, clear guidance | childish illustration or excessive rounding |
| Glassmorphism | translucent surfaces, backdrop blur, layered depth, sufficient contrast | applying blur to every container |
| Brutalist | raw hierarchy, strong contrast, intentional asymmetry, exposed structure | accidental inconsistency |

## Brand References

When a user names a brand, extract transferable traits and state them explicitly:

- Apple: editorial pacing, strong product focus, large typography, generous negative space, restrained palette.
- OpenAI: neutral content-first surfaces, simple hierarchy, low decoration, subtle interaction.
- Linear: compact productivity layout, crisp hierarchy, muted surfaces, fast keyboard-oriented interaction.
- Stripe: technical clarity, polished illustration, strong documentation patterns, deliberate color accents.

Never request literal replication of proprietary layouts, assets, or visual identity.
