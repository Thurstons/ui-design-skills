# UI Design Anti-patterns

Use these names only when the evidence supports them.

- **Over-containerization:** most sections use bordered or elevated cards even when spacing could establish grouping.
- **Nested-card hierarchy:** cards are nested repeatedly, producing visual boxes without clearer meaning.
- **CTA inflation:** multiple actions use primary styling, so no action reads as primary.
- **Visual center competition:** several regions simultaneously demand first attention.
- **Section fragmentation:** related content is split into many isolated blocks.
- **Token drift:** similar components use inconsistent color, radius, spacing, or typography values.
- **Decorative depth:** shadows, gradients, glow, or blur add visual weight without expressing state or hierarchy.
- **Density without grouping:** many items appear together without rhythm, alignment, labels, or progressive disclosure.
- **False affordance:** a visual treatment suggests clickability or editability that does not exist.
- **State ambiguity:** loading, disabled, selected, success, or error states are visually indistinguishable.

Describe observable symptoms and user impact. Do not use an anti-pattern label as a substitute for evidence.
